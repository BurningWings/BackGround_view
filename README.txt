WallpaperOnly

Run WallpaperOnly.exe to show this computer's current live desktop wallpaper.
Press any keyboard key or left-click to exit and restore windows, icons and taskbars.
Previously minimized windows stay minimized. Run the EXE again to use it again.

No wallpaper image is bundled, no screenshot is taken, and no personal desktop is loaded.
Windows Explorer must be running. Compatible desktop wallpaper players keep their desktop area visible.

To change the EXE icon, open IconSettings.exe beside the main EXE.
Choose a PNG/ICO image and click Apply icon.
Renamed executables can be found automatically or selected using Choose EXE.
Optional icon files belong in assets/icon.png or assets/icon.ico.

Windows 10/11 with .NET Framework 4.x is required. Installation is not required.
Exit wallpaper mode before applying an icon.
